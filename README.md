# Muse from Meta - download tracker (published copy)

Static web copy of `muse-download-tracker/muse_tracker.html`: Apptopia top-chart ranks, Google Play's exact
install count, App Store ratings, published download / DAU estimates, retention vs ChatGPT at launch, and
agent signup-page web visits. `rating_shots.html` shows the App Store rating screenshots (Muse vs ChatGPT 2023).
Generated by `muse-download-tracker/publish_site.py` on the source PC - do not edit here; every publish
overwrites the files.
